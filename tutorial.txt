Instalar python
Instalar Pycharm ou outra IDE

criar a venv
python -m venv nome_da_venv

Entrar na venv (Verificar se está na pasta raiz da venv)
source venv/bin/activate (UNIX)
venv/Scripts/activate.bat (Windows)

Instalar Django
pip install django

Criar projeto django
django-admin startproject nome_do_projeto_de_voces

Entrar na pasta do projeto
cd nome_do_projeto_de_voces

Rodar o servidor de desenvolvimento
python manage.py runserver

Criar a aplicação
python manage.py startapp nome_do_modulo_de_voces

Colocar em INSTALLED_APPS o nome da aplicação de vocês

Criar a pasta templates na raiz do projeto
Cadastrar pasta criada no arquivo settings.py

Prepara as migração do modelo de dados para o banco de dados relacional
python manage.py makemigrations

aplica o modelo de dados no banco de dados
python manage.py migrate

cria o super usuário no banco de dados
python manage.py createsuperuser

Fazer a modelagem de dados no arquivo models.py
prepara modelagem de dados com makemigrations
aplicar modelo com migrate
Registrar classes de modelo no admin.py
Criar arquivo urls.py para cada modulo

Configurar arquivos estaticos (CSS, JS, Imagens):
criar a pasta static na raiz do projeto
instalar biblioteca dj_static
pip install dj_static
adicionar Cling e MediaCling no asgi e wsgi
configurar STATIC_ROOT
Configurar STATICFILES_DIRS

Coletar arquivos estaticos
python manage.py collectstatic
